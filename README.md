# Utopia Group Website (Demo)
Static website built with HTML, CSS, and JavaScript.

## Deploy to Vercel
1. Upload `index.html` to the root of your GitHub repository.
2. In Vercel, import that repository.
3. Keep Framework Preset as Other and Build Command empty.
4. Set Output Directory to `.` if requested, then Deploy.

Notes:
- Social media account links are placeholders pending official URLs.
- Blog content and contact form are demo content; the form does not send email.
- Brand descriptions are initial drafts and should be verified before public launch.
